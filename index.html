rastro-finint

Módulo de investigación financiera del kit rastro. Cuatro herramientas independientes que corren enteramente en el navegador: identificación de entidad por cuenta/IBAN, análisis de BIN/tarjeta, verificación de direcciones cripto (BTC/ETH) con importación de trazas, y un normalizador de movimientos bancarios (CSV/XLSX/TXT/Norma 43) que construye un grafo de trazabilidad del dinero.

Alcance y límites — leer antes de usar

— El módulo IBAN valida checksum y, para España, identifica la entidad con una tabla de códigos parcial y editable (BOE/Banco de España si necesitas certeza total).
— El módulo BIN detecta red (Visa/Mastercard/Amex/...) y valida Luhn por algoritmo público; no incluye una base BIN completa incrustada porque no puedo garantizar su exactitud offline — puedes cargar tu propio CSV de rangos BIN para enriquecer la búsqueda localmente.
— El módulo cripto valida formato/checksum de direcciones de forma local (Web Crypto para SHA-256, sin red). No consulta saldo ni histórico en vivo — eso requiere un nodo o explorador externo. Para trazabilidad, importa un export CSV/JSON de un explorador (Etherscan, mempool.space, Blockchair, etc.) y el módulo reconstruye el grafo offline.
— El normalizador de movimientos incluye un parser de Norma 43 (AEB) por mejor esfuerzo: los anchos de campo pueden variar ligeramente entre bancos emisores, revisa siempre los resultados antes de usarlos como prueba.
— Ningún dato introducido se guarda entre sesiones. Al recargar la página se pierde todo. Diseñado así por custodia de la evidencia.

Cuentas / IBAN

Valida el dígito de control de un IBAN o de un antiguo CCC español, y localiza la entidad emisora a partir del código de banco.

Tabla de entidades (España) — editable

Listado parcial de códigos de entidad (4 dígitos) de uso habitual. Añade o corrige códigos según tus fuentes; se usa en vivo para la búsqueda de arriba.

CódigoEntidad

BIN / Tarjetas

Valida el número con el algoritmo de Luhn, detecta la red por rango IIN público y, si cargas tu propio listado de BIN, resuelve emisor.

Base de BIN local (opcional)

Carga un CSV propio con columnas bin (6-8 dígitos, prefijo), entidad, pais (opcional), tipo (opcional). Se usa para enriquecer la búsqueda de arriba, sin salir del navegador.

Cargar CSV de rangos BIN

Cripto — BTC / ETH

Verificación local de formato y checksum de direcciones (sin consulta a red). Para trazabilidad, importa un export de un explorador y el módulo reconstruye el grafo de movimientos.

Directorio local de direcciones conocidas (exchanges, etc.)

Mantén aquí tus propias direcciones verificadas (hot wallets de exchanges, sospechosos identificados...). Se usa para etiquetar automáticamente nodos en el grafo de abajo. Vive solo en esta sesión.

Importar traza (export de explorador)

Pega aquí un CSV o JSON exportado de un explorador de bloques (p.ej. CSV de Etherscan/mempool.space/Blockchair con columnas tipo hash, from, to, value, timestamp). El módulo detecta columnas automáticamente y construye el grafo dirigido.

Normalizador + Grafo de movimientos

Sube extractos bancarios en CSV, XLSX, TXT o Norma 43 (AEB). El módulo detecta el formato, normaliza los movimientos, redacta un resumen del análisis en lenguaje natural, señala patrones que pueden merecer revisión y construye un grafo dirigido de la trazabilidad del dinero.

Introduce la cuenta a la que pertenece el extracto. Si el extracto cubre varias cuentas propias, sepáralas con comas — todas se representarán como el mismo nodo central. No se intenta deducir desde las columnas del archivo.
